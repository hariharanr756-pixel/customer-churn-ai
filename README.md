# 🚀 Customer Churn Prediction App

A machine learning web application that predicts whether a customer is likely to churn based on their profile and service details.

🔗 **Live App:** https://customer-churn-ai-tjbpsljnpyx2zvnxpynxsl.streamlit.app/

---

## 📌 Overview

Customer churn is a critical problem for businesses. This project uses a trained machine learning model to predict churn probability and help take proactive actions.

This app allows users to:

* Enter customer details
* Get instant churn prediction
* Understand customer risk level

---

## ⚙️ Tech Stack

* Python
* Streamlit (Web App)
* Scikit-learn (ML Model)
* Pandas / NumPy (Data Processing)
* Joblib (Model Serialization)

---

## 🧠 Machine Learning

* Model trained on customer dataset (`churn.csv`)

* Features include:

  * Tenure
  * Monthly Charges
  * Contract Type
  * Internet Service
  * Payment Method

* Output:

  * Churn Prediction (Yes/No)

---

## 🚀 How to Run Locally

```bash
git clone https://github.com/hariharanr756-pixel/customer-churn-ai.git
cd customer-churn-ai
pip install -r requirements.txt
streamlit run app.py
```
